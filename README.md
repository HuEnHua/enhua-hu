# enhua-hu

Personal website. Single page, hand-written HTML, no build step — edit
`index.html` directly.

```
index.html              the site
images/                 favicon.jpg, profile2.jpg
static/files/           CI.pdf, CHHX_2026.pdf, HadadHu.pdf, PMCR.pdf, CV.pdf
_archive/               previous version, inactive — see _archive/README.md
```

To add a paper: drop the PDF in `static/files/` and add a link in the Research
section of `index.html`.
